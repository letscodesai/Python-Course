01

String Indexing: Accessing One Character

Definition: indexing means accessing a single character from a string by its position, using square brackets [].

Python numbers positions starting from 0, not 1 — the first character is always at index 0, the second at index 1, and so on.

Positive Indexing in Practice

Once you know the pattern, you can predict exactly which character any index will give you, before running the code.

Output

text[4] lands on the last character of "Hello" — because with 5 characters, the valid indexes are 0 through 4, not 1 through 5.

"Hello" has 5 letters. Is text[5] valid?

This is the single most common indexing mistake. Because counting starts at 0, the last valid index of a 5-character string is 4, not 5. We'll see exactly what happens when you try it in the next section.

04

Negative Indexing: Counting from the End

Definition: negative indexing accesses characters counting backwards from the end of the string. -1 is always the last character, -2 the second-last, and so on.

negative index positive index
negative.py
word = "Python"

print(word[-1])
print(word[-2])
print(word[-3])
Outputn o h

Every character in a string actually has two valid indexes — a positive one and a negative one, as the visualization shows. word[2] and word[-4] refer to the exact same character.

Indexing with Variables and Expressions

Whatever's inside the square brackets is what decides the character — it doesn't have to be typed as a plain number. A variable or a calculated expression works just as well, as long as it results in a whole number.

A few ways this error commonly shows up:

Off by one

Using an index equal to the string's length, forgetting the last valid index is length − 1.

Too far

An index far beyond the string's actual size.

Mixed up signs

Meaning to count from the end, but typing a positive index instead of negative.

07

String Slicing: start and stop

Definition: where indexing accesses one character, slicing extracts a whole section of a string, using the pattern string[start:stop:step]. We'll focus on start and stop first — step is coming up shortly.

start is where the slice begins, and stop is where it ends — but stop itself is not included in the result.

word[0:3] → "Pyt"

Characters at index 0, 1, and 2 are included — index 3 is where the slice stops, so it's left out, shown dashed above.

Predict the output — establishing the pattern
word = "Python"
print(word[0:2])
print(word[1:4])
print(word[2:5])
Output
Py
yth
tho

Each slice includes everything from start up to, but not including, stop. word[1:4] takes indexes 1, 2, and 3 — three characters, not four.

08

Step in Slicing

Definition: the full slicing pattern is string[start:stop:step] — step controls how many characters Python moves forward each time, instead of always moving one at a time.

step.py
word = "Python"
print(word[::2])
print(word[::3])
OutputPto Ph

A step of 2 takes every second character (indexes 0, 2, 4). A step of 3 takes every third (indexes 0, 3). Notice start and stop are both left blank here — up next is exactly what that means. Try it in the Slice Explorer above — leave start and stop empty and just fill in step.

09

Omitting start, stop, or Both

Any part of a slice can be left out. Python fills in a sensible default for whatever's missing.

word[:3]

No start given — Python assumes the very beginning.

word[3:]

No stop given — Python assumes all the way to the end.

word[:]

Neither given — the entire string.

omitting.py
word = "Python"
print(word[:3])
print(word[3:])
print(word[:])
OutputPyt hon Python
10

Negative Step: Reversing a String

A negative step moves backwards through the string instead of forwards — one specific negative step has a famous use.

Predict the output
word = "Python"
print(word[::-1])
Output
nohtyP

A step of -1 walks through the string one character at a time, back to front — with start and stop both omitted, that means the entire string, reversed. This is the standard, idiomatic way to reverse a string in Python.

Negative steps aren't only for full reversal — word[5:1:-1] walks backwards from index 5 down to (but not including) index 1, giving "noht". Try a few negative steps in the Slice Explorer above.

11

Negative Indexes in Slices

Everything you learned about negative indexing applies inside slices too — start and stop can each be negative, independently of each other.

negative_slices.py
word = "Python"
print(word[-4:])
print(word[:-2])
print(word[-5:-2])
Outputthon Pyth yth

word[-4:] starts 4 characters from the end and goes to the finish. word[:-2] takes everything except the last two characters. They combine exactly like positive indexes do — nothing new to learn, just applying what you already know.

One rule to keep in mind: with a normal (positive) step, start needs to land on an earlier position than stop, whether you write them as positive or negative numbers. Get that backwards — like word[-2:-5] — and you won't get an error, just an empty string, since there's nothing between them to include.

12

Slicing Beyond the String's Length

Here's a real difference between indexing and slicing worth remembering.

"Python" only has 6 characters. Will word[0:100] cause an error, the way word[100] does?
word = "Python"
print(word[0:100])
Output
Python

Slicing never errors for going out of range — it just stops at whatever the string actually has. word[0:100] quietly gives you the whole string. Indexing a single position that doesn't exist, like word[100], is the one that raises IndexError. Slicing is forgiving; indexing is exact.

Chapter Recap

A quick-glance reference for revising later.

Indexing

word[i] accesses one character. Zero-based.

Negative index

IndexError

Raised when an index doesn't exist in the string.

Slicing

word[start:stop] extracts a section. stop is excluded.

Omitted start

Assumes the beginning of the string.

Omitted stop

Assumes the end of the string.

step

word[::n] takes every nth character.

Negative step

word[::-1] reverses the string.

Slicing vs indexing

Slicing never errors out of range; indexing does.
