01

Getting Input From the User

Definition: user input is any information a person types into a running program while it's going. Without it, a program can only ever work with values already written into its code — input() is Python's built-in tool for asking the person using the program to type something.

Person types something→ input() receives it→ stored in a variable→ program uses it

When taking input, you can ask a prompt. A prompt is the message input() displays to tell the person what to type. It's entirely optional — input() on its own works too, it just won't say anything first.

no_prompt.py
input()
Waits silently for inputno message shown
with_prompt.py
input("What is your name? ")
Waits, but asks firstWhat is your name?

input() pauses everything. Once Python reaches an input() line, it stops and waits — nothing else in the program runs until the person types something and presses Enter.

input() Always Returns a String

This is the single most important thing to remember about input(): whatever the person types, Python stores it as a str — even if they typed nothing but digits.

If the user types 13, does input() give you the number 13?

Even though the person typed digits, Python stores exactly what was typed as text. age holds the string "13", not the number 13 — see for yourself below.

Type Conversion — Why We Need It?

Definition: type conversion (also called typecasting) means changing a value from one data type to another.

We need it because input() always hands back a string — even when we actually wanted a number to do maths with.

What happened? Since a and b are both text, + joins them together instead of adding their numbers — "5" + "3" becomes "53", not 8. To actually add the numbers, we need to convert them first.

Python gives you four conversion tools for this — each named after the data type it converts into:

int()

Converts to a whole number.

float()

Converts to a decimal number.

str()

Converts to text.

bool()

Converts to True or False.

The pattern you'll use constantly, combining input() with one of these:

pattern.py
age = int(input("How old are you? "))
Reading right to leftinput() returns a string → int() converts it → the result is stored in age
05

int() Up Close

Definition: int() converts a suitable value into a whole number. It works on numeric-looking strings and on floats — with one important detail for floats.

Predict the output — does this round?
print(int(7.9))
Output
7

int() doesn't round — it simply removes everything after the decimal point. 7.9 becomes 7, not 8. The same is true for negative numbers: int(-7.9) gives -7, not -8.

Three Flavors of Division: /, // and %

Python has three separate operators involving division, and each answers a different question. Here's what all three give you for the same pair of numbers.

7 / 27 // 27 % 2
Result3.531
Question it answersWhat's the exact result?How many whole times does 2 fit into 7?What's left over after that?

/ (Division): ordinary division always produces a float result, even when the numbers divide evenly.

Predict the output
print(10 / 2)
print(7 / 2)
Output
5.0
3.5

Notice 10 / 2 gives 5.0, not 5 — / always returns a float, so the type stays consistent no matter what numbers you divide.

// (Floor Division): it divides, then rounds the result down to the nearest whole number — not simply "chops off the decimal" the way int() does.

Predict the output — this is where floor division gets interesting
print(7 // 2)
print(-7 // 2)
Output
3
-4

7 // 2 is 3 — no surprise there. But -7 // 2 is -4, not -3. That's because "floor" always rounds down toward negative infinity: -3.5 rounds down to -4, not up toward zero.

% (Modulus): it gives the remainder left over after division.

Predict the output
print(10 % 3)
print(15 % 5)
print(17 % 4)
Output
1
0
1

A remainder of 0 — like 15 % 5 — means one number divides evenly into the other. That's a genuinely useful thing to know, and % is the tool that tells you.

Exponentiation **

Definition: ** raises a number to a power — multiplying a number by itself a set number of times.

power.py
print(2 ** 3)
print(5 ** 2)
Output8 25

2 ** 3 means "multiply 2 by itself 3 times": 2 * 2 * 2 = 8.

5 ** 2 — often read as "5 squared" — means 5 * 5 = 25.

13

Order of Operations: BIDMAS

Definition: when an expression has more than one operator, Python doesn't just work left to right — it follows the same order of operations you learned in maths class, remembered by BIDMAS.

B

Brackets

I

Indices / powers

D M

Division & Multiplication

A S

Addition & Subtraction

Does division always happen before multiplication, since D comes before M in "BIDMAS"?

Division and multiplication are actually equal in precedence — same for addition and subtraction. When operators share a precedence level, Python evaluates them in the order they appear, left to right.

Predict the output
print(2 + 3 * 4)
Output
14

Multiplication happens before addition: 3 * 4 is 12 first, then 2 + 12 = 14.

Now with brackets — predict the output
print((2 + 3) * 4)
Output
20

Brackets are evaluated first no matter what: 2 + 3 = 5, then 5 * 4 = 20. Brackets are how you override Python's default order whenever you need to.
