String Concatenation: Joining Strings Together

Definition: concatenation means joining two or more strings together, end to end, using the + operator.

The simplest form joins string literals directly.

When Types Don't Match: The Concatenation Error

+ only knows how to join two strings. Hand it a string and a number, and it stops the program — it won't guess what you meant.

Debug this

Output
Press Run or Check…

Why this happens: age is an int, not a str, and + refuses to silently guess how to combine a number with text. The fix uses str() from Chapter 4 — nothing new to learn there, just applying it: print("Age: " + str(age)).

This is one of the most common early mistakes in Python — whenever you see an error mentioning str and another type together, this mismatch is usually why.

04

String Repetition: Multiplying Strings

Definition: string repetition means repeating a string a set number of times, using the * operator between a string and a whole number.

repeat_word.py
print("Hi " * 3)
OutputHi Hi Hi
divider.py
print("*" * 20)
Output********************
Predict the output — same symbol, very different meaning
print(3 * 3)
print("3" * 3)
Output
9
333

3 * 3 is ordinary multiplication between two numbers, giving 9. "3" * 3 is string repetition — Python repeats the text "3" three times, giving "333". Same * symbol, completely different behaviour, depending on what's on each side of it.

05

Common Mistakes with Repetition

Repetition only accepts a whole number as the repeat count. A couple of edge cases are worth knowing before you hit them by surprise.

Will Python round 2.5 down to 2 and repeat the string twice?
print("hi" * 2.5)

Python doesn't round it for you — a repeat count must be a whole number (int). A float like 2.5 stops the program with an error instead of guessing what you meant.

Predict the output — this one's a genuine surprise
print("hi" * -1)
Output
(nothing — an empty string)

Unlike the float case, a negative repeat count doesn't cause an error at all — Python just treats "repeat it -1 times" as "repeat it zero times," giving back an empty string. No error, just nothing.

07

What Exactly Does len() Count?

Every character counts — letters, digits, spaces, and punctuation alike. Nothing is skipped.

Predict the output — mind the spaces
print(len(" hi "))
Output
4

Two letters and two spaces — all four characters count, including the ones you might not notice at a glance.

Predict the output — mind the punctuation
print(len("Hello, World!"))
Output
13

The comma, the space, and the exclamation mark are each one character too, just like any letter.
