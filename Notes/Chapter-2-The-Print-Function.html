01

Meet print(): Your Program's Voice

print() is a built-in Python command that displays whatever you give it on the screen. Everything else your code does happens quietly, behind the scenes — print() is what actually shows up.

Think of your program like a kitchen. A chef can chop, mix, and cook all day, but the customer never sees any of it — they only see what gets placed on the serving window.

print() is that serving window. Nothing your code works out will appear on screen unless it passes through print() first.

print_syntax.py
print("Hello!")
■ print — the command you're using ■ ( ) — this is how you use it ■ what's inside, in quotes — the message to display

Try it above: type just hello — no quotes, no print(). Python replies NameError: name 'hello' is not defined. Without quotes, Python assumes hello is the name of something it should already know, and it isn't. Quotes tell Python "this is just text."

02

What Goes Inside the Parentheses

You can print two kinds of things so far: text (called a string, always wrapped in quotes) and numbers (typed plainly, no quotes at all). They can look identical on screen, but Python treats them very differently underneath.

Will these two lines print the exact same text?
print(5)
print("5")
Output
5
5

Identical on screen — but 5 is a number Python can do maths with, while "5" is just a character that looks like one.

Will these two lines print the same result?
print(2 + 3)
print("2" + "3")
Output
5
23

2 + 3 adds numbers, giving 5. "2" + "3" joins text end to end, giving "23".

A preview, not the full story: text vs numbers gets its own chapter later. For now, just remember: numbers have no quotes, text always does.

03

Single Quotes vs Double Quotes

Python gives you two ways to mark text: single quotes 'like this' and double quotes "like this". Neither is "more correct" — both give exactly the same result, as long as the quote you open with matches the one you close with.

single_quotes.py
print('Hello, World!')
OutputHello, World!
double_quotes.py
print("Hello, World!")
OutputHello, World!

So when does it matter which one you pick? Mainly when your text itself contains a quote mark.

Debug this 
print('It's raining today')
SyntaxError: unterminated string literal

Something about this line confuses Python. Can you spot what?

print("It's raining today")

The apostrophe in It's is a single quote character. Python reads the first ' as the string starting, and the apostrophe inside It's as the string already ending — leaving the rest dangling. Switching the outer quotes to double quotes fixes it instantly.

04

Printing Multiple Things at Once

print() doesn't limit you to one thing. You can hand it several pieces, separated by commas, and it prints all of them on one line, one after another.

"Python", "is", "fun"

three separate pieces, joined by commas — each comma marks where one piece ends and the next begins

05

The Default Behaviour of print()

print() quietly does two things for you every time, unless you say otherwise: it puts a space between each piece you give it, and it moves to a new line once it's done.

space_between.py
print("Python", "is", "fun")
OutputPython is fun
new_line.py
print("First line")
print("Second line")
OutputFirst line Second line

Neither of those is an accident — they're just Python's defaults: the settings it uses automatically when you don't specify your own. You're allowed to change both, which is exactly what the next two sections cover.

06

sep: Choosing What Goes Between

sep is a setting you can add inside print()'s parentheses to control what Python places between each piece you give it. Its default is a single space " " — that's why pieces normally appear with a space between them. Write sep="..." with whatever separator you like inside the quotes.

sep_example.py
print("2026", "08", "23", sep="-")
Output2026-08-23

end: Choosing What Happens After

end is a setting that controls what Python adds after everything you gave it has been printed. Its default is a newline "\n" — that's why every new print() normally starts on its own fresh line. Change it, and you change whether the next thing printed lands beside it or below it.

print("Done!")

08

sep vs end: Don't Mix Them Up

Both are about spacing, but they control two completely different moments.

sepend
Affectsgaps between the pieces, inside one print()what comes after that whole print() is finished
Default" " — a space"\n" — a new line
Analogythe glue holding words together in one sentencethe punctuation mark placed after the whole sentence
Only matters if…you gave it 2 or more piecessomething else gets printed right after
Predict the output — both together
print("A", "B", "C", sep="-", end=" | ")
print("Next")
Output
A-B-C | Next

sep="-" joins A, B and C with dashes. end=" | " replaces the usual new line, so "Next" lands right after it on the same line.

09

Escape Sequences: Typing the Impossible

An escape sequence is a two-character combination, starting with a backslash \, that stands in for a character you couldn't otherwise type inside a string — either because it isn't a visible character, or because typing it directly would confuse Python.

SequenceMeansWhy you'd need it
\nNew lineYou can't press Enter inside a string — this inserts a line break instead.
\tTabAdds horizontal spacing, handy for lining up columns.
\\One backslashSince \ normally starts an escape, \\ is how you print an actual backslash.
\"Double quoteLets you use " inside a string already wrapped in double quotes.
\'Single quoteLets you use ' inside a string already wrapped in single quotes.

10

Quotation Marks and Escaping Characters

Back in Section 3, we fixed a broken apostrophe by switching from single to double quotes. That works — but it's not your only option. You can keep the same quote type and simply escape the troublesome character instead.

option_1.py
print("It's raining today")
OutputIt's raining today
option_2.py
print('It\'s raining today')
OutputIt's raining today

Both print the same thing. The first switches quote type. The second keeps single quotes and uses \' to say "this apostrophe is part of the text, not the end of the string."

The outer string starts with ", but "hello" has its own unescaped double quotes — Python reads the first of those as the string ending early. Escaping both inner quotes with \" tells Python they're just characters to display.

13

Chapter Recap

A quick-glance reference for revising later.

print()

Displays whatever you give it on screen.

Multiple pieces

print() can take more than one, separated by commas.

Quotes

Mark text as a string. Single and double both work, as long as they match.

sep

What goes between the pieces. Default: a space.

end

What comes after everything is printed. Default: a new line.

\n

Inserts a new line inside a string.

\t

Inserts a tab (horizontal spacing).

\\

Prints a single literal backslash.

\"

Prints a double quote inside a double-quoted string.

\'

Prints a single quote inside a single-quoted string.

NameError

Happens when Python sees an unquoted word it doesn't recognise.
